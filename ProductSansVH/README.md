# Product Sans VH
Product Sans font with Vietnamese lignatures support. Downloaded from https://www.dafontvn.com/2021/07/tai-font-product-sans-viet-hoa-tron-bo.html.  
This font is what Google Sans is based of off, mainly used in Google product logos & brandings. Personally I like this font better since it looks less spaced out than the other. 

Import link: https://github.com/YMica-OSE/BunnyFonts/raw/fonts/ProductSansVH.json
